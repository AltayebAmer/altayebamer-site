خيارات النشر
ما الذي يفعله هذا الزر فعلاً؟ يرفع ملف content.json فقط — وهو نسخة احتياطية من بيانات اللوحة. لا تقرأه صفحات الموقع، فالموقع HTML ثابت ومحتواه مكتوب داخل الصفحات نفسها. لذلك رفعه لا يغيّر شيئاً مرئياً في الموقع.
لتغيير ما يراه الزائر استخدم: مدير صور الصفحات (PIM) · مدير صور المعرض (GIM) · محرر الملفات · الرقع (Patches) — فهذه وحدها تكتب في صفحات الموقع مباشرة.

🌐 Cloudflare — AltayebAmer.com
النطاق والاستضافة كلاهما على Cloudflare ✅ — الموقع يُنشر عبر Cloudflare Pages مباشرةً من مستودع GitHub (لا يُستخدم GitHub Pages).
1. Cloudflare Pages → Connect to Git → اختر المستودع
2. Build command = (فارغ) · Output directory = /
3. Custom domains → altayebamer.com → Always Use HTTPS ✅
إعدادات GitHub
كيف يعمل النظام
1️⃣ أنشئ مستودعاً على GitHub: altayebamer-site
2️⃣ في Cloudflare Pages: Connect to Git → اختر المستودع، واترك Build command فارغاً وOutput directory = /
3️⃣ أضف رمز الوصول (Personal Access Token) هنا — يُستخدم للكتابة في المستودع مباشرة
4️⃣ التعديلات من PIM / GIM / محرر الملفات / الرقع تُكتب في ملفات الصفحات، وCloudflare ينشرها خلال دقيقة
5️⃣ اربط النطاق altayebamer.com من لوحة Cloudflare Pages
إعدادات المستودع
⚠️ عن أمان التوكن: يُحفظ داخل متصفح هذا الجهاز فقط (لا يُرفع لأي خادم)، لكنه ليس مشفّراً — أي إضافة متصفح أو شخص يصل لجهازك يستطيع قراءته. استخدم توكناً Fine-grained مقصوراً على مستودع الموقع بصلاحية Contents: Read and write فقط، واحذفه من GitHub فور الانتهاء إن كنت على جهاز مشترك.

أدوات الموقع
🔗 إصلاح روابط التنقل (Nav Fix)
يصحّح مسارات روابط التنقل داخل <nav id="nav"> (مثل gallery/index.html ← ../gallery/index.html) دون حذف أو إضافة أي رابط. ابدأ دائماً بالفحص بلا تعديل.
🩺 فحص صحة مانيفست الصور
يتحقق أن كل رابط صورة مسجّل في مدير الصور (PIM) ومدير المعرض (GIM) ما زال موجوداً فعلاً في ملف الصفحة على GitHub. إن ظهر أي رابط «مفقود» فلن يعمل استبداله — وهذا سبب رسالة «الرابط القديم غير موجود».
📱 إصلاح Responsive — جميع الأجهزة
يُضيف CSS لجميع أحجام الشاشات: موبايل، تابلت، آيباد، لابتوب، ديسكتوب.
